creating a virtual environment using terminal/command prompt:

conda create (-p/-n) {virtual_enve_name} python=={version_name} -y

-p: to create a virtual environment in present working directory like current path
-n: to create a virtual environment is created in the default path were anaconda is installed, like a new directory.

example: conda create -p venv python==3.12

ACTIVATING environment: conda activate {virtual_enve_name}/

virtual environment: to manage packages for different projects and versions.

Installing packages:
1. pip install method: eg: [pip install numpy]
2. By using Requirements.txt file: list all the python packages name

to use this: pip install -r requirments.txt -----> installs all the packages listed in the file; -r is to requirement 

**benefits** of adding python or conda to environmentpath or path variables:
So, when environment variables are enabled during installation, helpful 'notices' 
are created on the computer's information board. 
This helps the computer locate and run Python and Anaconda correctly, making programming easier.
